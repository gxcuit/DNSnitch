# Directory Structure

> Layout of the Wails v2 + Vue 3 + TypeScript frontend in `gui/frontend/`.

---

## Overview

One single-page Vue app, no router and no store library. It renders results produced by the Go backend; it never computes findings itself. Go side: `gui/app.go` (see `.trellis/spec/backend/gui-bindings.md`).

---

## Directory Layout

```
gui/frontend/
├── index.html
├── package.json / package-lock.json   (lock file is committed; install with npm ci)
├── vite.config.ts, tsconfig*.json
├── public/.gitkeep                     copied into dist/ on every build (keeps dist/.gitkeep alive)
├── dist/.gitkeep                       tracked so `go:embed all:frontend/dist` compiles before any build
├── wailsjs/                            GENERATED by Wails (go/main/App.*, go/models.ts, runtime/) — never hand-edit
└── src/
    ├── main.ts                         createApp(App)
    ├── App.vue                         layout + drop wiring (OnFileDrop) + overlays
    ├── style.css                       global CSS variables, light/dark themes
    ├── labels.ts                       label(labels, group, code), SEVERITIES, baseName()
    ├── i18n/zh.ts                      GUI chrome strings only
    ├── composables/useCheck.ts         the single state owner (see state-management.md)
    └── components/                     SummaryBar, FindingList, FindingCard, SourceView
```

---

## Module Organization

- New UI piece → a component in `src/components/` that receives data via props and emits events; state changes go through `useCheck()`.
- New backend data → add it to the Go binding first, run `wails generate module`, then consume the generated type.
- New chrome text → `src/i18n/zh.ts`. Backend-provided text (findings, severity/role/level names, error messages) must not be copied into the frontend.

---

## Naming Conventions

- Components: PascalCase `.vue` files, one component per file.
- Composables: `useXxx.ts` in `src/composables/`.
- Backend codes (severity `high`, role `affected`, level `plain` …) stay as codes in state; convert to display text only at render time via `label()`.
